# data/ — материалы по конкурентам

Ниша: **производство спортивной одежды**.

| Папка | Что внутри | Для какого эндпоинта |
|---|---|---|
| `texts/` | Короткие описания брендов: позиционирование, линейки, УТП | `POST /analyze_text` (скопировать текст в форму) |
| `screenshots/` | Скриншоты лендингов, их сохраняет парсер при `/parse_demo` и `/parse_competitors` | `POST /analyze_image` |
| `reports/` | PDF-отчёты и презентации конкурентов, если есть (положить вручную) | Текст из них идёт в `/analyze_text` |

Тексты в `texts/` — это учебные сводки по открытой информации о брендах. Перед выводами их стоит сверить с сайтами конкурентов.
